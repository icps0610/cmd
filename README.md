# cmd — Windows 常用指令工具

把裝機、維護時常用的 Windows 指令（CMD、PowerShell、登錄檔、快捷鍵）整理成一個純靜態網頁，打開就能查、點一下就能複製。不需要後端或安裝任何套件。

## 功能

### 指令瀏覽頁 `index.html`

- **卡片式清單**：每個指令一張卡片，顯示標題、分類標籤與指令內容。
- **點一下就複製**：點指令區塊即可將內容複製到剪貼簿，並顯示「已複製」提示；反白選取部分文字時不會觸發，方便只複製其中一段。
- **預設排序**：依指令內容由短到長排列，長度相同時依標題。
- **標籤排序**：卡片右上角會顯示分類標籤，點一下標籤，含該標籤的指令會排到最前面並捲回頁面頂端；再點一次恢復預設排序。
- **下載 cmd.txt**：將全部指令匯出成一份文字檔（含標題註解），方便離線使用。
- **響應式版面**：深色主題，手機與桌機皆可瀏覽。

### 指令管理頁 `manager.html`

- **新增／編輯／刪除**指令，編輯視窗支援 `Tab` 縮排與 `Ctrl + Enter` 快速儲存。
- **分類標籤（多選）**：編輯時可點選多個既有標籤，或直接輸入新標籤。
- **搜尋**：依標題、標籤或指令內容即時篩選。
- **排序與瀏覽頁一致**：預設依指令內容由短到長排列，點卡片上的標籤可切換為標籤排序；儲存時 `commands.js` 也依內容長度寫入。
- **直接寫回 `commands.js`**：透過瀏覽器的 File System Access API 儲存，第一次選擇檔案後會記住位置；不支援的瀏覽器則改為下載檔案。

## 檔案說明

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 指令瀏覽頁 |
| `manager.html` | 指令管理頁 |
| `commands.js` | 指令資料 |

## 資料格式

`commands.js` 內每個指令的格式如下：

```js
{
  "title": "DNS查詢",
  "code": "nslookup google.com",
  "tags": ["網路"]
}
```

## 使用方式

1. 以瀏覽器開啟 `index.html` 即可瀏覽與複製指令。
2. 要增修指令時開啟 `manager.html`（建議使用 Chrome 或 Edge），修改後儲存至 `commands.js`。
